# Telecom Churn Prediction Using Machine Learning

## Project Overview
This project uses Artificial Intelligence (AI) and Machine Learning to predict whether a telecom customer will leave the service (Churn) or stay based on behavioral data.

## Tech Stack Used
- **Language:** Python
- **Environment:** Google Colab
- **Libraries:** Pandas, Scikit-Learn

## Machine Learning Model
- **Algorithm:** RandomForestClassifier
- **Features Used:** `tenure` (Months with company), `MonthlyCharges`

## Results
- **Model Accuracy:** 75.44%
